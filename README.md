## 🚀 Uruchomienie

Bez zewnętrznych bibliotek, np.:

```bash
python "Day 14/Higher or Lower Project/main.py"
```

W każdym folderze `task.py` / `main.py` to mój kod, a `solution.py` — wzorcowe rozwiązanie z kursu.
